| Boundary | Description |
|----------|-------------|
| browser origin (http LAN vs https) -> app | App behaviour depends on runtime secure-context flag |
| app -> external link | WarningBar links out to the secure address |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-12 | Spoofing | WarningBar link target | mitigate | href and visible text both come from SECURE_URL (build-time constant from GITHUB_REPOSITORY_OWNER), so the user can read the exact URL; no query/user input is interpolated |
| T-01-13 | Tampering | XSS via rendered text | mitigate | All strings are static constants rendered through React text nodes; no dangerouslySetInnerHTML (grep-able), no user input in Phase 1 |
| T-01-14 | Elevation of privilege | Mic access from placeholder page | mitigate | MicPlaceholderScreen contains no audio code; grep gate forbids getUserMedia / new AudioContext in src |
| T-01-15 | Denial of service | Inline note timers | accept | Single 3 s timer, cleared on unmount/re-tap; negligible |
</threat_model>
