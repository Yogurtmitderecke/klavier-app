<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local repo -> public GitHub repo | Everything pushed becomes world-readable |
| GitHub Actions runner -> GitHub Pages | OIDC-authenticated deploy of build output |
| third-party actions -> CI | Action code runs with pages:write / id-token:write |
| browser -> github.io | Public static site over TLS |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-06 | Tampering | Third-party GitHub Actions | mitigate | Keep full 40-char commit-SHA pins from the official Vite sample for all five actions; verify grep in Task 1 |
| T-01-07 | Elevation of privilege | Workflow GITHUB_TOKEN | mitigate | Minimal permissions block (contents: read, pages: write, id-token: write); no secrets used; deploy only from main (github-pages environment default rule) |
| T-01-08 | Information disclosure | .claude/settings.local.json, credentials | mitigate | Ignored via .gitignore and `git check-ignore` gate before push; PAT fallback is entered only into Git Credential Manager, never written to a file |
| T-01-09 | Information disclosure | .planning/ + CLAUDE.md in public repo | accept | Contain no secrets; user explicitly confirms in Task 2 Teil D, otherwise stop before push |
| T-01-10 | Tampering | Broken/untested build reaching users | mitigate | CI runs lint, tests, build and the base-path grep before upload-pages-artifact; failing steps abort deploy |
| T-01-11 | Spoofing / Tampering in transit | Live site | transfer | GitHub Pages terminates TLS and enforces HTTP->HTTPS redirect (verified 301 in Task 3) |
</threat_model>
